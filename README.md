# Kadodo Africa

Kadodo Africa is a platform for discovering and supporting African businesses.

## Getting Started

To run the project locally, follow these steps:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```
